# План: колокация компонентов страниц и оболочки

## 1. Контекст

В `src/components` сейчас смешаны **общие** UI-примитивы (`Button`, `Select`, `Badge`) и блоки, используемые только экраном тренировки на главной (`ExerciseControlBar`, `Stage`, `WorkoutStatusBar`) или оболочкой приложения (`AppNav`). У `HomePage` уже есть локальная папка `pages/HomePage/components/` с `HomeLayout`; остальная презентация главной пока лежит в общем `components`.

## 2. Цель

- Держать в **`src/components`** только то, что имеет смысл переиспользовать на разных экранах (примитивы и нейтральные виджеты).
- Разместить **виджеты главной (тренировка)** рядом со страницей: `src/pages/HomePage/components/<Name>/` по тем же соглашениям, что и `HomeLayout` (tsx, styled, index).
- Разместить **навигацию приложения** рядом с `App`: `src/App/components/AppNav/`.
- **Наблюдаемое поведение и внешний вид** не меняются.

## 3. Зависимости между слоями

- Контейнеры слотов (`pages/HomePage/containers/*`) рендерят презентацию и импортируют доменные виджеты главной из барреля **`../components`** (под `HomePage`), а типы вроде `SelectOption` для селекторов — из **`src/components`**.
- Виджеты главной, которым нужны примитивы, импортируют их из барреля **`../../../../components`** (относительно файла в `HomePage/components/<Widget>/`).

## 4. Проверка отсутствия регрессии

- `npm run build`, `npm test` без ошибок.
- Ручная проверка: навигация между маршрутами; главная — селекты, кнопки, статусы, сцена.

## 5. Критерии готовности

- В `src/components/index.ts` остаются только общие экспорты (примитивы и их типы).
- `AppPageLayout` импортирует `AppNav` из `./components` (баррель `App/components`).
- `HomePage/components/index.ts` реэкспортирует `HomeLayout` и виджеты тренировки.
- Документация в `docs/components.md` согласована с новой границей (кратко).
