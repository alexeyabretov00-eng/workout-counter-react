# План: одна кнопка «Старт / Пауза»

Связанный чеклист: [combined-start-pause-button-implementation-tasks.md](./combined-start-pause-button-implementation-tasks.md).

## 1. Контекст

В блоке управления сессией в `App.tsx` сейчас две отдельные кнопки: «Старт» и «Пауза». Они вызывают те же действия, что и голосовые команды (`start` / `pause` из `useWorkoutSession`), но занимают место и дублируют смысл «включено / на паузе».

## 2. Цель

Объединить управление запуском и паузой в **одну кнопку**, сохранив текущее поведение сессии:

- при активном выполнении (`isRunning === true`) кнопка показывает «Пауза» и вызывает `pause()`;
- когда сессия не выполняется (в том числе после паузы или до первого старта) — «Старт» и `void start()`;
- правила `disabled` как у текущей «Старт»: недоступна, пока модель не готова или идёт инициализация камеры; во время активного выполнения блокировка не нужна (пауза всегда доступна).

Голосовые команды и хук `useWorkoutSession` **не меняются**.

## 3. Критерии готовности

- В UI одна кнопка вместо пары «Старт» + «Пауза».
- Сценарии старт → пауза → старт (возобновление) и сброс / стоп камеры работают как раньше.
- README и архитектурная документация отражают новый UI; при необходимости уточнён справочник голосовых команд (связь UI ↔ действия).

## 4. Границы

Не входит: изменение текстов голосовых фраз, логики `isRunning` / `isPaused` в `useWorkoutSession`, стилей кроме минимально необходимого для той же кнопки (если потребуется).
