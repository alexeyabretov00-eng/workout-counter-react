# Задачи реализации перехода на styled-components

Связанный план: [styled-components-migration-plan.md](./styled-components-migration-plan.md).

Используйте чекбоксы по мере выполнения.

---

## Этап A — Подготовка инфраструктуры

- [ ] **A1.** Добавить зависимости `styled-components` и `@types/styled-components` с exact-версиями в `package.json`.
- [ ] **A2.** После изменения зависимостей выполнить чистую переустановку: удалить `node_modules`, удалить `package-lock.json`, затем выполнить `npm install`.
- [ ] **A3.** Подключить `ThemeProvider` в корневом UI-слое и вынести базовую тему в отдельный модуль.
- [ ] **A4.** Добавить `createGlobalStyle` для базовых глобальных правил (`html/body/#root`), не меняя пользовательское поведение.

## Этап B — Миграция UI-каркаса

- [ ] **B1.** Перенести layout-контейнеры и основные блоки интерфейса на styled-компоненты.
- [ ] **B2.** Перенести базовые контролы (кнопки, select, статусные элементы) с сохранением текущих состояний `disabled/hover/focus/active`.
- [ ] **B3.** Проверить визуальную стабильность интерфейса в основных сценариях: старт, пауза, сброс, стоп камеры, отдых.

## Этап C — Локальные стили и очистка

- [ ] **C1.** Перенести оставшиеся локальные CSS-классы в styled-компоненты и пропсы вариаций.
- [ ] **C2.** Удалить неиспользуемые CSS-правила/файлы после подтверждённого переноса каждого участка.
- [ ] **C3.** Привести стиль именования styled-компонентов к единой конвенции в проекте.

## Этап D — Документация и проверка

- [ ] **D1.** Обновить `README.md` и при необходимости `docs/architecture.md`, зафиксировав подход со `styled-components`.
- [ ] **D2.** Добавить короткие рекомендации для новых UI-компонентов (токены темы, структура styled-компонентов).
- [ ] **D3.** Прогнать `npm run lint`, `npm run test`, `npm run build` и зафиксировать результат проверки перед завершением этапа реализации.

---

## Приоритизация (рекомендация)

1. **Сначала:** A1-A4 (инфраструктура и тема).
2. **Затем:** B1-B3 (основной UI-контур).
3. **После:** C1-C3 и D1-D3 (очистка и закрепление практик).
