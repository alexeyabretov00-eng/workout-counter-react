# Задачи реализации плана обновления документации

Связанный план: [documentation-update-plan.md](./documentation-update-plan.md).

Используйте чекбоксы по мере выполнения.

---

## Этап A — Аудит

- [ ] **A1.** Пройти полный пользовательский сценарий в браузере и зафиксировать расхождения с [README.md](../../README.md) (список bullet points для правок).
- [ ] **A2.** Сверить `npm` скрипты в [package.json](../../package.json) с разделом «Скрипты» README; отметить отсутствующие или лишние формулировки.
- [ ] **A3.** Зафиксировать минимальные требования к браузеру и окружению (камера, микрофон, Speech API, загрузка модели MediaPipe) в черновике для раздела README или `docs/browser-requirements.md`.

## Этап B — README: продукт и пользователь

- [ ] **B1.** Обновить блок «Что умеет сейчас»: голос (старт/пауза/сброс/стоп камеры/длительность отдыха), таймер отдыха, озвучка повторений — по факту кода в `App.tsx` и `useWorkoutSession.ts`.
- [ ] **B2.** Добавить подраздел «Голосовое управление» с таблицей или списком команд; при перегрузе README — вынести в `docs/voice-commands.md` и дать ссылку.
- [ ] **B3.** Описать настройку длительности отдыха (кнопки и/или голос) и поведение отсчёта на canvas.
- [ ] **B4.** В «Скрипты» добавить `npm run preview` с одной строкой назначения.

## Этап C — README: разработка

- [ ] **C1.** Актуализировать «Архитектура»: роль `src/app/useWorkoutSession.ts`, связь `camera` → `pose` → `exercises` → `render`.
- [ ] **C2.** Добавить краткую схему потока данных (текстом или mermaid в README — по желанию команды).
- [ ] **C3.** Расширить «Как добавить новое упражнение»: ссылка на тесты `src/exercises/__tests__/`, напоминание зарегистрировать детектор в `registry.ts`.

## Этап D — Доп. документы и связи

- [ ] **D1.** (Опционально) Создать `docs/voice-commands.md` и перенести туда полный перечень фраз из кода с группировкой по действиям.
- [ ] **D2.** (Опционально) Создать `docs/browser-requirements.md` с требованиями и типичными ошибками.
- [ ] **D3.** В README одной-двумя фразами сослаться на [todo.md](../../todo.md) как на бэклог идей.

## Этап E — Качество

- [ ] **E1.** После правок документации выполнить `npm run lint` и `npm run test`; исправить расхождения, если документация ссылалась на неверное поведение.
- [ ] **E2.** Ревью README: орфография, единый стиль списков, актуальность версий стека (React, Vite, TypeScript) при необходимости одной строкой в «Стек» или в начале раздела разработки.

2. **Затем:** B2, B3, C3, D3.
3. **По мере роста проекта:** D1, D2, E2.
