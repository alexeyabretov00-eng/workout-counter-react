# Требования к браузеру и окружению

## Минимальная конфигурация

- **Браузер:** современный **Chromium** (Chrome, Edge, Opera и т.п.) — так надёжнее всего работают **Web Speech API** (распознавание и синтез) и типичный набор API для камеры.
- **Камера:** устройство и разрешение пользователя на доступ к камере (`getUserMedia`).
- **Контекст страницы:** для доступа к камере страница должна открываться по **HTTPS** или с **localhost** (ограничение браузеров).
- **Сеть:** при первом запуске приложение загружает модель **MediaPipe Pose** (`pose_landmarker_lite`) через `@mediapipe/tasks-vision`; нужен доступ в интернет (или заранее настроенное кэширование CDN — в стандартной сборке используется загрузка с CDN MediaPipe).

## Микрофон и голос

- Для **распознавания команд** нужен **микрофон** и разрешение в браузере.
- Для **озвучки повторений и фраз отдыха** используется **speech synthesis** (`speechSynthesis`). В части браузеров синтез может быть отключён, без русского голоса или нестабилен в фоновых вкладках.

## Типичные проблемы

| Симптом | Возможная причина |
|---------|-------------------|
| Камера не включается | Нет HTTPS/localhost; другое приложение заняло камеру; запрет в настройках ОС или браузера. |
| «Голос: не поддерживается» | Браузер без `SpeechRecognition` (например, не Chromium; в Safari поддержка ограничена). |
| «Голос: доступ к микрофону запрещён» | В блоке адресной строки разрешите микрофон для сайта. |
| Модель долго грузится или не грузится | Нет сети, блокировщик, корпоративный прокси, сбой CDN. В строке состояния обычно видно `Модель: загружается` или `Модель: не загружена`. |
| Нет скелета / низкий confidence | Плохое освещение, тело не полностью в кадре, одежда сливается с фоном. |

## Отладка

- Консоль разработчика (F12): сообщения об ошибках камеры, загрузки модели и Speech API.
- В строке состояния приложения отображаются статусы модели (`загружается`, `загружена`, `не загружена`), камеры и голоса.
