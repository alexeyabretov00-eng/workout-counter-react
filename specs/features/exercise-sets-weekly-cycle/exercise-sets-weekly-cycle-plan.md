# План фичи: недельные сеты упражнений

Ссылка на правила процесса: `README.md`, `specs/features/README.md`.

## Контекст

Сейчас админка управляет только справочником упражнений, а сущности «сет упражнений» для недельного плана нет.
Нужно добавить создание сетов для 7-дневного цикла, где каждый сет закреплен за конкретным днем недели и пользователем.

## Цели

- Добавить модель «сет упражнений» с привязкой к:
  - дню недели;
  - пользователю;
  - списку упражнений.
- Реализовать создание сета через API.
- Добавить в `AdminModule` отдельную вкладку для создания сетов.
- Ограничить выбор пользователя при создании:
  - `admin` и `superadmin` могут выбрать пользователя вручную;
  - `user` не может выбрать пользователя, сет автоматически привязывается к себе.

## Нецели

- Редактирование и удаление сетов (в рамках этой задачи делаем именно создание).
- Встраивание сетов в рантайм тренировки на главной странице.
- Переработка существующего управления ролями.

## Технический подход

1. **БД и сервер**
   - Добавить таблицы для сетов и связи «сет-упражнение».
   - Реализовать серверные функции создания и чтения списков (для отображения в админке после создания).
   - Добавить endpoint создания с валидацией входных данных.
   - Внедрить ролевую логику назначения `userId` на сервере.

2. **Клиентский API и состояние**
   - Добавить DTO и API-клиент для сетов.
   - Расширить `AdminModule` store/thunks/selectors для загрузки упражнений, пользователей и создания сетов.

3. **UI в админке**
   - Добавить вкладки в админке: существующий каталог упражнений и новая вкладка создания сетов.
   - На вкладке сетов реализовать форму:
     - название сета;
     - день недели;
     - множественный выбор упражнений;
     - выбор пользователя (только для ролей `admin`/`superadmin`).
   - Добавить базовую таблицу созданных сетов.

4. **Проверки**
   - Обновить/добавить тесты для backend/frontend контрактов.
   - Прогнать `npm run lint`, `npm run test`.

## Критерии готовности

- Через API можно создать сет с днем недели и набором упражнений.
- У созданного сета всегда есть `userId`:
  - у `user` берется из токена;
  - у `admin`/`superadmin` берется из выбранного значения (или из токена при отсутствии выбора).
- В админке есть отдельная вкладка для создания сетов.
- После создания сет отображается в списке на вкладке.
