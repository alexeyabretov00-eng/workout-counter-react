# Задачи реализации: глобальная шина событий (singleton)

Связанный план: [global-event-bus-plan.md](./global-event-bus-plan.md).

Используйте чекбоксы по мере выполнения.

---

## Этап A — Контракт и структура файлов

- [ ] **A1.** Добавить каталог `src/utils/eventBus/` (рядом с остальными утилитами в `src/utils/`).
- [ ] **A2.** Ввести **единый модуль имён событий** (например `src/utils/eventBus/events.ts`): константы логических **`type`** для `emit` / `on`; запретить дублирование имён вне этого файла по соглашению ревью.
- [ ] **A3.** При необходимости описать **`EventMap`** (логический тип события → тип `detail`) в согласии с константами из A2; публичный **`EventHandler`** — `(detail: unknown) => void` или сужение через перегрузки/`EventMap` на шине.
- [ ] **A4.** Баррель `src/utils/eventBus/index.ts` с **явными** реэкспортами публичного API (без `export *`); при необходимости добавить явные реэкспорты в корневой `src/utils/index.ts` по соглашению импортов проекта.

## Этап B — Класс шины и singleton

- [ ] **B1.** Реализовать **`EventBus`**: транспорт **`CustomEvent`** и **`window.dispatchEvent` / `addEventListener`**, префикс DOM-имени (например **`app:`**) + логический **`type`**; **`emit(type, detail?)`**; **`on(type, handler)`** с возвратом функции отписки; при **`typeof window === 'undefined'`** — no-op **`emit`** и **`on`** возвращает **`() => {}`**.
- [ ] **B2.** Экспортировать **`export const eventBus = new EventBus()`** — единственный экземпляр; без фабрик «инстанс на страницу».
- [ ] **B3.** В тестах полагаться на вызов отписки из **`on`** (и при необходимости **`afterEach`**); отдельный **`clear()`** не обязателен, если это зафиксировано в коде тестов.
- [ ] **B4.** Юнит-тесты (с **`window`**, например jsdom): подписка, **`emit`**, отписка, несколько слушателей на один **`type`**.

## Этап C — Интеграция с React (без хуков шины)

- [ ] **C1.** На пилотной странице: подписка только через **`useEffect`**: сохранить функцию отписки из **`eventBus.on`**, вернуть её из эффекта как cleanup. **Не** добавлять хуки в `src/utils/eventBus`.

## Этап D — Пилотное использование

- [ ] **D1.** Выбрать один модуль и связанную страницу: заменить прямую навигацию из модуля на **`eventBus.emit`** с каноническим событием из списка A2.
- [ ] **D2.** На странице подписаться через **`useEffect` + eventBus.on** и выполнить **`navigate`** (или иной эффект) в обработчике.
- [ ] **D3.** Убедиться, что при размонтировании страницы слушатель снимается (нет лишних срабатываний при повторном заходе).

## Этап E — Документация и проверка

- [ ] **E1.** У барреля шины или в архитектурном документе зафиксировать: эмит в модулях, подписка на страницах через **`useEffect`**, **без** хуков в пакете шины.
- [ ] **E2.** `npm run lint`, `npm run build`, `npm test`.
