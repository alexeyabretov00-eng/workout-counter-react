# Планы исправлений

- **Активные** исправления — подкаталоги здесь же: `fixes/<краткое-имя>/` (не используйте `_archive` для новой работы).
- После **реализации** исправления (чеклист закрыт, код и документация в нужном состоянии) **перенесите** каталог исправления в `fixes/_archive/<то же имя>/` **отдельным третьим коммитом** цикла (см. раздел «Планирование фич и исправлений» в корневом [README.md](../README.md)). В markdown-файлах добавьте по одному `../` в путях к корню репозитория (например, `../../README.md` → `../../../README.md`).
- **Архив** только для чтения и истории; продолжение работы по той же теме оформляйте как новое исправление в `fixes/<имя>/` с планом и чеклистом; правки `README` / `docs/`, относящиеся к исправлению, включайте в его чеклист и делайте в том же цикле реализации.
