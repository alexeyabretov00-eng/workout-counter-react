# План: лишняя перерисовка при смене упражнения

## Контекст

При выборе упражнения обновляется `exerciseId` в `WorkoutLogicLayout`. Значение одного `WorkoutSessionChromeContext` пересобирается целиком (`useMemo` зависит от `exerciseId` и колбэков сессии), поэтому все потребители контекста (в т.ч. статус-бар без привязки к упражнению) получают обновление. Дополнительно без `React.memo` у `AppLayout` ре-рендер провайдера пробрасывается к слотам (включая stage и заголовок).

## Цель

Ограничить ре-рендер: при смене упражнения обновлять преимущественно панель управления; статус-бар и каркас layout — только если изменились их данные.

## Подход

1. Разделить chrome-контекст на два: срез для панели управления (упражнение, отдых, сессия, действия) и срез для статус-бара (модель, камера, голос, пауза, ошибка камеры).
2. Обернуть `AppLayout` в `React.memo` при неизменных пропах-слотах.

## Проверка

- Смена упражнения в селекте: селект и кнопки обновляются; статус-бар не мигает без изменения модели/камеры/голоса.
- Старт/пауза/стоп, отдых, голос — без регрессий.
