# План: новое упражнение "Армейский жим"

**Статус:** в работе.

## 1. Контекст и проблема

Сейчас в приложении доступны только два упражнения (`Подъем на бицепс` и `Приседания`), поэтому пользователь не может считать повторения для жима над головой в той же сессии и через голосовой выбор упражнения.

## 2. Цель

Добавить в реестр упражнений новый детектор `Армейский жим` с подсчетом повторений по углу локтя и проверкой положения рук над головой, а также поддержкой выбора из выпадающего списка и голосом.

## 3. Подход

- Реализовать отдельный детектор `armyPressDetector` по аналогии с существующими детекторами.
- Ввести фазовую модель (`down` -> `up` -> `down`) на основе среднего угла левого/правого локтя.
- Для перехода в верхнюю фазу требовать, чтобы кисти были выше плеч и на уровне головы (по ключевой точке `nose`), чтобы не считать разводку рук в стороны.
- Зарегистрировать упражнение в `exerciseRegistry`, чтобы оно появилось в UI и в голосовом lookup.
- Добавить тест на валидный цикл движения и инкремент повторения.
- Добавить тест-антикейс, что движение в стороны с прямыми руками не засчитывается как верхняя фаза.

## 4. Критерии готовности

- В селекте упражнений появляется пункт `Армейский жим`.
- По завершенному циклу `внизу -> вверху -> внизу` детектор возвращает `repDelta = 1`.
- Движение с прямыми руками в стороны без подъема над головой не переводит фазу в `up` и не дает повтор.
- Голосовые фразы для армейского жима переключают упражнение в неактивной сессии.
