# Архив планов исправлений

Здесь хранятся завершённые исправления, перенесённые из `specs/fixes/<имя>/` после закрытия чеклиста и завершения реализации.

- Архив только для чтения и истории.
- Для продолжения темы создавайте новое исправление в `specs/fixes/<новое-имя>/` с новым планом и чеклистом.
