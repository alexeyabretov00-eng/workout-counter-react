# Голосовые команды

Язык распознавания в приложении: **ru-RU**. Фразы сопоставляются с нормализованным текстом (нижний регистр, без пунктуации; границы слов учитываются, чтобы не срабатывать на подстроки внутри слов).

Источник констант в коде: `src/pages/HomePage/hooks/useSpeechRecognition.ts` (массивы команд и `REST_MINUTE_COMMANDS`), а также `voiceAliases` в файлах детекторов и поля `name` упражнений.

## Статусы в интерфейсе

| Статус        | Значение |
|---------------|----------|
| не поддерживается | В браузере нет Web Speech API (`SpeechRecognition` / `webkitSpeechRecognition`). |
| запуск        | Распознавание поднимается при монтировании приложения. |
| слушаю        | Распознавание активно. |
| переключитесь на эту вкладку | Вкладка в фоне (`document.hidden`): распознавание остановлено до возврата на страницу. |
| доступ к микрофону запрещён | Пользователь отклонил доступ к микрофону. |
| ошибка распознавания | Сбой API распознавания (см. консоль браузера при отладке). |

## Управление сессией

В интерфейсе действия **Старт** и **Пауза** представлены **одной кнопкой**: при активном выполнении отображается «Пауза», иначе — «Старт». Голосовые команды ниже по-прежнему разделены по смыслу.

| Действие | Фразы (любая из списка) |
|----------|-------------------------|
| Старт (если модель загружена: запускает новую сессию или возобновляет после паузы) | `старт`, `начинаем упражнение`, `начать упражнение` |
| Пауза | `пауза`, `поставь на паузу`, `остановись` |
| Сброс счётчика и фазы | `сброс`, `сбросить`, `обнулить`, `сбрось` |
| Остановка упражнения + отдых выбранной длительности | `стоп`, `стоп упражнение`, `закончи упражнение` |

Между повторениями одной и той же команды действует пауза около **900 ms** (кроме команд отдыха, см. ниже).

### Когда команды сессии срабатывают

- `Старт` срабатывает только при загруженной модели и когда сессия не находится в активном выполнении.
- Если сессия была на паузе, `Старт` возобновляет её без сброса счётчика и фазы.
- `Пауза` срабатывает только во время активной сессии.
- `Сброс` обнуляет счётчик и фазу только **во время активного выполнения** (когда в UI на основной кнопке «Пауза»); в простое, на паузе и на таймере отдыха не обрабатывается — как и кнопка «Сброс».
- Команды из строки «Остановка упражнения…» выше и кнопка **Стоп** останавливают сессию и запускают отдых на длительность из текущей настройки; срабатывают только во время активного выполнения (не в простое, не на паузе, не на отдыхе).

## Длительность отдыха (голосом)

Задаёт **минуты** для **следующего** завершения сессии кнопкой **Стоп** или голосовыми командами из строки «Остановка упражнения…» выше. Пауза между срабатываниями команд отдыха — около **4 s**.

| Минуты | Фразы |
|--------|--------|
| 1 | `отдых 1`, `отдых 1 минута`, `отдых 1 минуту`, `отдых одна минута` |
| 2 | `отдых 2`, `отдых 2 минуты`, `отдых две минуты` |
| 3 | `отдых 3`, `отдых 3 минуты`, `отдых три минуты` |
| 5 | `отдых 5`, `отдых 5 минут`, `отдых пять минут` |

В UI доступны те же значения: 1, 2, 3 и 5 минут (селектор «Отдых»).

## Переключение упражнения

Срабатывает по **нормализованному** названию упражнения из реестра и по синонимам из `voiceAliases` в детекторе.

### Подъём на бицепс (`biceps-curl`)

- Имя: `подъем на бицепс`
- Синонимы: `бицепс`, `подъем на бицепс`, `подъемы на бицепс`, `сгибание рук`, `сгибания рук`, `подъем гантели на бицепс`

### Приседания (`squat`)

- Имя: `приседания`
- Синонимы: `присед`, `приседания`, `приседание`

### Армейский жим (`army-press`)

- Имя: `армейский жим`
- Синонимы: `армейский жим`, `жим стоя`, `жим над головой`, `жим штанги стоя`, `оверхед пресс`, `overhead press`

### Наклоны головы вправо-влево (`head-side-tilt`)

- Имя: `наклоны головы вправо-влево`
- Синонимы: `наклоны головы`, `наклон головы`, `голова вправо влево`, `шея вправо влево`, `наклоны шеи`

При добавлении нового упражнения расширяйте `voiceAliases` в соответствующем файле детектора и при необходимости обновляйте этот документ.

## Ограничения

- Нужен браузер с поддержкой Web Speech API (типично Chromium). Подробнее: [browser-requirements.md](./browser-requirements.md).
- Требуется разрешение на **микрофон**.
- Качество распознавания зависит от микрофона, шума и дикции; при необходимости используйте кнопки в UI.
