# План исправления: единый тип статусов

## 1. Контекст

В коде используются два отдельных, но пересекающихся типа статусов:

- `CameraStatus` в `useCameraStream`;
- `ModelStatus` в `useWorkoutSession`.

Из-за этого правила статусов дублируются и типы живут локально, а не в общем месте.

## 2. Цель

Свести статусы камеры и модели к одному общему типу и вынести его в глобальное хранилище типов.

## 3. Подход

- Добавить каталог `src/types` с `index.ts` и общим типом статуса.
- Удалить локальные декларации `CameraStatus` и `ModelStatus` в хуках.
- Обновить импорты и использования типов в `useCameraStream`, `useWorkoutSession`, `App`.
- Актуализировать краткую архитектурную документацию под новый `src/types`.

## 4. Критерии готовности

- В проекте есть один общий тип статуса в `src/types`.
- `useCameraStream` и `useWorkoutSession` используют этот тип, без локальных дубликатов.
- `App.tsx` использует общий тип статуса через импорт из глобальных типов.
- Линтер и тесты проходят.
