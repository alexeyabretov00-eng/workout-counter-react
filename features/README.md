# Планы фич

- **Активные** фичи — подкаталоги здесь же: `features/<краткое-имя>/` (не используйте `_archive` для новой работы).
- После **реализации** фичи (чеклист закрыт, код и документация в нужном состоянии) **перенесите** каталог фичи в `features/_archive/<то же имя>/` **отдельным третьим коммитом** цикла фичи (см. раздел «Планирование фич» в корневом [README.md](../README.md)). В markdown-файлах добавьте по одному `../` в путях к корню репозитория (например, `../../README.md` → `../../../README.md`).
- **Архив** только для чтения и истории; продолжение работы по той же теме оформляйте как новую фичу в `features/<имя>/` с планом и чеклистом; правки `README` / `docs/`, относящиеся к фиче, включайте в её чеклист и делайте в том же цикле реализации.

Примеры завершённых фич: [features/\_archive/README.md](./_archive/README.md).
