# Задачи реализации React Router (три страницы)

Связанный план: [react-router-routing-plan.md](./react-router-routing-plan.md).

Используйте чекбоксы по мере выполнения.

---

## Этап A — Зависимости

- [x] **A1.** Добавить в `package.json` зависимости **`react-router`** и **`react-router-dom`** с **точными** версиями (без `^` / `~`), взятыми из одного релиза пакетов, чтобы версии ядра и DOM-обёртки совпадали.
- [x] **A2.** Выполнить чистую переустановку: удалить `node_modules`, удалить `package-lock.json`, выполнить `npm install`.

## Этап B — Страницы и маршруты

- [x] **B1.** Создать `src/pages/` с подпапками `HomePage/`, `AdminPage/`, `ExerciseHistoryPage/` по соглашениям проекта (`index.ts`, явные реэкспорты; стили заглушек — через `styled-components` и тему при необходимости).
- [x] **B2.** Реализовать **HomePage**: перенести из текущего `src/App.tsx` разметку с `WorkoutLogicLayout` и `AppLayout` (импорты из `./components`, `./containers`, `./logic`).
- [x] **B3.** Реализовать **AdminPage** и **ExerciseHistoryPage** как заглушки с понятными заголовками (текст вроде «Админка» / «История упражнений»).
- [x] **B4.** Добавить баррель `src/pages/index.ts` и при необходимости зарегистрировать публичный API (не использовать `export *`).

## Этап C — Интеграция роутера

- [x] **C1.** Ввести константы путей (например `/`, `/admin`, `/history`) в одном модуле и использовать их в `Route` и `Link`.
- [x] **C2.** Обернуть приложение в `BrowserRouter` (удобная точка: `src/main.tsx` сразу под `ThemeProvider` или согласованное с командой место).
- [x] **C3.** В `src/App.tsx` (или выделенном модуле маршрутов) объявить `Routes` / `Route` для трёх страниц; при необходимости обработать неизвестный путь (`Navigate` к `/` или простая заглушка).
- [x] **C4.** Добавить навигацию между страницами (`Link`), чтобы не зависеть от ручного ввода URL при проверке.

## Этап D — Проверка

- [x] **D1.** Убедиться, что на `/admin` и `/history` не монтируется `WorkoutLogicLayout` (нет лишней инициализации камеры/сессии на этих экранах).
- [x] **D2.** Прогнать `npm run lint`, `npm run build`, `npm test`.
- [x] **D3.** Ручная проверка: главная ведёт себя как раньше; переходы на админку и историю и обратно работают.
