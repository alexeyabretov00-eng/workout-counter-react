# Планы фич

- **Активные** фичи — подкаталоги здесь же: `specs/features/<краткое-имя>/` (не используйте `_archive` для новой работы).
- После **реализации** фичи (чеклист закрыт, код и документация в нужном состоянии) **перенесите** каталог фичи в `specs/features/_archive/<то же имя>/` **отдельным третьим коммитом** цикла фичи (см. раздел «Планирование фич и исправлений» в корневом `README.md`). Ссылки на файлы в markdown оформляйте **путём от корня** в обратных кавычках (без цепочек `../`) — см. `docs/markdown-paths.md`.
- **Архив** только для чтения и истории; продолжение работы по той же теме оформляйте как новую фичу в `specs/features/<имя>/` с планом и чеклистом; правки `README` / `docs/`, относящиеся к фиче, включайте в её чеклист и делайте в том же цикле реализации.

Примеры завершённых фич: [архив фич](./_archive/README.md).
