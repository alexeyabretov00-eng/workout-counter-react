# Задачи реализации внедрения Storybook

Связанный план: [storybook-adoption-plan.md](./storybook-adoption-plan.md).

Используйте чекбоксы по мере выполнения.

---

## Этап A — Подготовка и инициализация

- [ ] **A1.** Добавить необходимые Storybook-пакеты для React/Vite в `package.json` с exact-версиями.
- [ ] **A2.** После изменения зависимостей выполнить чистую переустановку: удалить `node_modules`, удалить `package-lock.json`, затем выполнить `npm install`.
- [ ] **A3.** Инициализировать Storybook в проекте и проверить успешный локальный запуск.

## Этап B — Базовая конфигурация

- [ ] **B1.** Настроить `main` и `preview` конфигурации Storybook под структуру проекта.
- [ ] **B2.** Подключить глобальные стили/тему для корректного визуального соответствия приложению.
- [ ] **B3.** Добавить базовые параметры (layout/controls/backgrounds) только в необходимом минимуме.

## Этап C — Истории для ключевых компонентов

- [ ] **C1.** Определить список приоритетных UI-компонентов для первичного покрытия историями.
- [ ] **C2.** Добавить истории с ключевыми состояниями (`default`, `disabled`, и другие релевантные).
- [ ] **C3.** Проверить корректный рендер и соответствие состояний историй реальному UI.

## Этап D — Документация и проверка

- [ ] **D1.** Обновить `README.md` и/или `docs/` инструкциями по запуску и использованию Storybook.
- [ ] **D2.** Описать минимальные правила добавления/поддержки stories для новых UI-компонентов.
- [ ] **D3.** Финально прогнать `npm run lint`, запуск приложения и команды Storybook (run/build) перед завершением этапа реализации.

---

## Приоритизация (рекомендация)

1. **Сначала:** A1-A3 (инфраструктура и рабочий запуск Storybook).
2. **Затем:** B1-B3 (стабильная конфигурация под проект).
3. **После:** C1-C3 и D1-D3 (истории, документация, финальная проверка).
