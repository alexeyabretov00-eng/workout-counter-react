# Планы фич

- **Активные** фичи — подкаталоги здесь же: `features/<краткое-имя>/` (не используйте `_archive` для новой работы).
- После **реализации** фичи (чеклист закрыт, код и документация в нужном состоянии) **перенесите** каталог фичи в `features/_archive/<то же имя>/` одним коммитом (или отдельным PR). В markdown-файлах добавьте по одному `../` в путях к корню репозитория (например, `../../README.md` → `../../../README.md`).
- **Архив** только для чтения и истории; новые правки по той же теме оформляйте как новую фичу или обновляйте `README` / `docs/` напрямую, если объём маленький.

Примеры завершённых фич: [features/\_archive/README.md](./_archive/README.md).
