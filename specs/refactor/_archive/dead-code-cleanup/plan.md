# План: убрать неиспользуемые публичные экспорты

## Контекст

В проекте есть несколько публичных экспортов, которые не используются приложением, тестами и сборкой. Они увеличивают поверхность API и затрудняют поддержку.

## Цель

- Удалить подтвержденно неиспользуемые экспорты без изменения поведения приложения.
- Сохранить работоспособность сборки и линтинга.

## Область изменений

- `src/api/authClient.ts`, `src/api/index.ts`
- `src/routes/index.ts`
- `src/modules/HomeModule/store/index.ts`
- `src/App/components/AppPageLayout/index.ts`
- `src/App/components/index.ts`

## Проверка отсутствия регрессии

- `npm run lint`
- Проверка импортов: отсутствие обращений к удаленным экспортам по коду.
