# Задачи реализации перехода на styled-components

Связанный план: [styled-components-migration-plan.md](./styled-components-migration-plan.md).

Используйте чекбоксы по мере выполнения.

---

## Этап A — Подготовка инфраструктуры

- [x] **A1.** Добавить зависимость `styled-components` с exact-версией в `package.json`. Пакет **v6** поставляет типы для TypeScript; отдельный `@types/styled-components` не требуется.
- [x] **A2.** После изменения зависимостей выполнить чистую переустановку: удалить `node_modules`, удалить `package-lock.json`, затем выполнить `npm install`.
- [x] **A3.** Подключить `ThemeProvider` в корневом UI-слое и вынести базовую тему в отдельный модуль (`src/theme`).
- [x] **A4.** Добавить `createGlobalStyle` для базовых глобальных правил (`html`/`body`, `box-sizing`), не меняя пользовательское поведение.

## Этап B — Миграция UI-каркаса

- [x] **B1.** Перенести layout-контейнеры и основные блоки интерфейса на styled-компоненты (`AppLayout`, `ExerciseControlBar`, `Stage`, `WorkoutStatusBar`).
- [x] **B2.** Перенести базовые контролы (`Button`, `Select`) с сохранением текущих состояний `disabled`/`hover`/`focus`/`active`.
- [x] **B3.** Проверить визуальную стабильность интерфейса в основных сценариях: старт, пауза, сброс, стоп камеры, отдых — по согласованию с планом (smoke вручную + автоматические проверки ниже).

## Этап C — Локальные стили и очистка

- [x] **C1.** Перенести оставшиеся локальные CSS-классы в styled-компоненты и пропсы вариаций (в т.ч. бейджи статусов через `$status` / `$ready`).
- [x] **C2.** Удалить неиспользуемые CSS-файлы после переноса (`*.css` в `src/components`, `App.css`, `index.css`).
- [x] **C3.** Именование styled-компонентов: `Root`, секции, осмысленные имена для вложенных узлов; transient props для модификаторов.

## Этап D — Документация и проверка

- [x] **D1.** Обновить `README.md` и `docs/architecture.md`, зафиксировав подход со `styled-components` и каталог `src/theme`.
- [x] **D2.** Обновить рекомендации для новых UI-компонентов: `docs/components.md`, `docs/src-layout.md`, `.cursor/rules/components.mdc`, `AGENTS.md`.
- [x] **D3.** Прогнать `npm run lint`, `npm run test`, `npm run build` — все три команды завершились успешно после реализации.
