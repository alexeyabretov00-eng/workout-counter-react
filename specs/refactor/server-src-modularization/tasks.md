# Задачи: декомпозиция крупных файлов в `server/src`

План: `specs/refactor/server-src-modularization/plan.md`

## Чеклист

- [ ] Спроектировать целевую структуру модулей в `server/src` и зафиксировать карту переносов из `index.ts`, `db.ts`, `validation.ts`.
- [ ] Вынести обработчики/маршруты из `server/src/index.ts` в отдельные модули и оставить в `index.ts` только сборку приложения.
- [ ] Разделить `server/src/db.ts` на более мелкие модули по областям ответственности с сохранением текущих контрактов.
- [ ] Разделить `server/src/validation.ts` на тематические схемы/валидаторы и обновить импорты.
- [ ] Проверить, что поведение API не изменилось (коды/форматы ответов и сценарии ошибок).
- [ ] Прогнать проверки (`npm run lint`, `npm run test` или доступный эквивалент) и устранить найденные проблемы.
