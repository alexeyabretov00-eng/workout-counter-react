# План фичи: наклоны головы вправо-влево

Ссылка на правило процесса: `README.md` (раздел «Планирование фич и исправлений»).

## Контекст

В приложении уже есть упражнения для рук и ног, но нет упражнения для шеи. Нужен отдельный детектор для наклонов головы вправо-влево, чтобы пользователь мог считать повторения и переключаться на упражнение через интерфейс и голос.

## Цель

Добавить новое активное упражнение «Наклоны головы вправо-влево» в реестр детекторов с базовым устойчивым подсчётом повторов и покрытием unit-тестом.

## Область изменений

- Новый файл детектора в `src/exercises/*Detector.ts`.
- Обновление тестов детекторов в `src/exercises/__tests__/detectors.test.ts`.
- Без изменений UI-компонентов: упражнение должно появиться автоматически через реестр.

## Этапы реализации

1. Реализовать детектор наклонов головы с фазами и порогами по смещению головы относительно плеч.
2. Добавить голосовые алиасы и метрики в результат детектора.
3. Добавить тесты: присутствие в реестре и подсчёт повтора на последовательности вправо-влево.
4. Прогнать тесты `npm run test`.

## Критерии готовности

- В `exerciseRegistry` появляется новый активный детектор.
- Детектор считает 1 повтор на последовательности «наклон вправо -> наклон влево».
- Существующие тесты не ломаются.
