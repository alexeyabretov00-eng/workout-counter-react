# План исправления: подпись кнопки «Стоп» вместо «Стоп камера»

Ссылка на общие правила: корневой `README.md`, `specs/fixes/README.md`.

**Этап 1 (коммит «план»):** в репозитории присутствуют только файлы в `specs/fixes/rename-stop-button/` — без правок `src/`, `docs/` и прочего кода продукта. **Этап 2:** реализация по чеклисту и отдельный коммит.

## Контекст

В панели управления сессией кнопка завершения сессии и запуска таймера отдыха подписана «Стоп камера». Для UI — короткая подпись «Стоп». Голосовые синонимы остановки сессии формулируются через **упражнение** (`стоп`, `стоп упражнение`, `закончи упражнение`), а не через «камеру».

## Цель

- Заменить видимый текст кнопки на «Стоп» и согласовать `aria-label`.
- Обновить `SHUTDOWN_COMMANDS` в `src/App.tsx` и справочник в `docs/voice-commands.md`.
- Обновить упоминания кнопки и сценария остановки в `README.md`, `docs/architecture.md`, `CONSTITUTION.md` (где речь о UI и голосе).

## Этапы

1. Правка `src/App.tsx`: подпись и `aria-label` кнопки; массив `SHUTDOWN_COMMANDS`.
2. Синхронизация `docs/voice-commands.md`, `README.md`, `docs/architecture.md`, `CONSTITUTION.md`.
3. `npm run lint`.

## Критерии готовности

- В интерфейсе на кнопке отображается «Стоп».
- Документация не противоречит UI и коду; фразы остановки согласованы с `SHUTDOWN_COMMANDS`.
- Линтер проходит для затронутых файлов.
