# Задачи реализации перехода на новый набор ESLint-пакетов

Связанный план: [eslint-packages-migration-plan.md](./eslint-packages-migration-plan.md).

Используйте чекбоксы по мере выполнения.

---

## Этап A — Подготовка зависимостей

- [x] **A1.** Добавить пакеты `eslint-config-prettier`, `eslint-plugin-prettier`, `eslint-plugin-react`, `eslint-plugin-react-hooks`, `eslint-plugin-simple-import-sort` в `package.json` с exact-версиями.
- [x] **A2.** После изменения зависимостей выполнить чистую переустановку: удалить `node_modules`, удалить `package-lock.json`, затем выполнить `npm install`.
- [x] **A3.** Проверить, что зависимости установились корректно и проектные npm-скрипты продолжают работать.

## Этап B — Обновление ESLint-конфигурации

- [x] **B1.** Обновить `eslint.config.js`: подключить новые плагины и `eslint-config-prettier`.
- [x] **B2.** Включить правила для React и React Hooks на базовом рекомендованном уровне.
- [x] **B3.** Настроить правила `simple-import-sort/imports` и `simple-import-sort/exports`.
- [x] **B4.** Интегрировать проверку форматирования через `prettier/prettier` (если требуется выбранной стратегией команды).

## Этап C — Адаптация существующего кода

- [x] **C1.** Выполнить `npm run lint` и классифицировать нарушения по приоритету.
- [x] **C2.** Исправить критичные нарушения (React hooks/import sort/formatting) в затронутых файлах.
- [x] **C3.** Проверить, что исправления не изменили фактическое поведение UI и логики.

## Этап D — Документация и проверка результата

- [x] **D1.** Обновить `README.md` и/или `docs/` с кратким описанием нового линтинг-стека и ключевых правил.
- [x] **D2.** Уточнить рекомендации по организации импортов и обработке lint-ошибок для новых PR.
- [x] **D3.** Финально прогнать `npm run lint` и `npm run build` (и тесты, если затронуты) перед завершением этапа реализации.

---

## Приоритизация (рекомендация)

1. **Сначала:** A1-A3 (зависимости и стабильная установка).
2. **Затем:** B1-B4 (конфигурация и правила).
3. **После:** C1-C3 и D1-D3 (адаптация кода, документация, финальная проверка).
