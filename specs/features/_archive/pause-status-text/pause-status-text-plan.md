# План: текст статуса паузы

**Статус:** завершено.

## 1. Контекст и проблема

Сейчас при нажатии на кнопку `Пауза` тренировка останавливается, но в интерфейсе нет явного текстового статуса, что упражнение именно приостановлено. Пользователь видит только косвенное поведение по отсутствию обновлений.

## 2. Цель

Показывать пользователю понятный текст `Упражнение приостановлено` после нажатия на паузу.

## 3. Подход

- Добавить явный флаг состояния паузы в `useWorkoutSession`.
- Устанавливать флаг в `true` при `pause()` и сбрасывать в `false` при `start()` и остановке сессии.
- Пробросить состояние паузы в `App.tsx` и отрисовать текстовый индикатор в статусной области.
- В области `.stage` показывать текстовый экран паузы вместо последнего кадра канваса.

## 4. Критерии готовности

- После нажатия `Пауза` отображается текст `Упражнение приостановлено`.
- При возобновлении через `Старт` текст исчезает.
- Текст не отображается во время обычного состояния без активной паузы.
- В режиме паузы на сцене нет «замороженного» последнего кадра.
