# Планы исправлений

- **Активные** исправления — подкаталоги здесь же: `fixes/<краткое-имя>/` (не используйте `_archive` для новой работы).
- Любой **hotfix/хотфикс** (в том числе быстрый визуальный hotfix) оформляйте как исправление в `fixes/<краткое-имя>/`.
- После **реализации** исправления (чеклист закрыт, код и документация в нужном состоянии) **перенесите** каталог исправления в `fixes/_archive/<то же имя>/` **отдельным третьим коммитом** цикла (см. раздел «Планирование фич и исправлений» в корневом `README.md`). Ссылки на файлы в markdown — по соглашению в `docs/markdown-paths.md` (путь от корня в `` `...` ``, без `../`).
- **Архив** только для чтения и истории; продолжение работы по той же теме оформляйте как новое исправление в `fixes/<имя>/` с планом и чеклистом; правки `README` / `docs/`, относящиеся к исправлению, включайте в его чеклист и делайте в том же цикле реализации.
