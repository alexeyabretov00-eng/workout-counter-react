# План: в админке раскрытие строки показывает не то упражнение

## Контекст

В `ExerciseCatalogManager` в таблице упражнений используется один общий экземпляр `Form` для редактирования данных раскрытой строки. Из-за этого при раскрытии разных строк в форме остаются данные первого раскрытого упражнения (наблюдалось как данные `biceps-curl`).

## Цель

Сделать так, чтобы каждая раскрытая строка таблицы в админке отображала и редактировала данные именно своего упражнения.

## Подход

1. Убрать общий `editForm` для всех строк.
2. Рендерить отдельную форму редактирования для каждой раскрытой строки с собственным состоянием.
3. Добавить регрессионный тест на раскрытие разных строк и проверку корректных значений.

## Проверка

- Раскрытие любой строки показывает `slug`, `name`, `detectorKey` и остальные поля именно выбранного упражнения.
- Сохранение из раскрытой строки вызывает `onUpdate` с корректным `id`.
- Тест на `ExerciseCatalogManager` покрывает кейс с несколькими упражнениями и разными значениями.
