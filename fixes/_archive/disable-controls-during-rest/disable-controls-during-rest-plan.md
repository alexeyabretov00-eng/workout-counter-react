# План исправления: неактивные «Сброс» и «Стоп камера» во время отдыха

Ссылка на общие правила: [README.md](../../../README.md), [fixes/README.md](../../README.md).

## Контекст

После «Стоп камера» показывается таймер отдыха на canvas. Кнопки **Сброс** и **Стоп камера** остаются активными, хотя в фазе отдыха они не нужны и вводят в заблуждение.

## Цель

Пока идёт обратный отсчёт отдыха, кнопки **Сброс** и **Стоп камера** должны быть неактивны (`disabled`). Голосовой **Сброс** в эту фазу не выполнять (согласованность с UI). Голосовой «стоп камера» во время отдыха и так не срабатывает при выключенной камере — отдельно менять не требуется.

## Этапы

1. В `useWorkoutSession` отслеживать фазу активного отдыха (включение при старте таймера, выключение по завершении, при отмене отдыха через **Старт** и при остановке сессии без отдыха).
2. В `App.tsx`: `disabled` на обе кнопки по флагу; для голоса **Сброс** — игнорировать команду во время отдыха.
3. Обновить `README.md` и `docs/voice-commands.md`.
4. Проверить линтер по изменённым файлам.

## Критерии готовности

- Во время таймера отдыха кнопки **Сброс** и **Стоп камера** неактивны.
- После окончания отдыха или при **Старт** кнопки снова доступны по прежним правилам.
- Документация согласована с поведением; нет новых замечаний линтера в затронутых файлах.
