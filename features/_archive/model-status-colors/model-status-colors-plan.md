# План: цветовые статусы модели

## 1. Контекст и проблема

Сейчас в строке состояния приложение показывает только два текстовых состояния модели: `загружена` и `загружается`. При ошибке загрузки пользователь не получает явного сигнала, что модель не инициализировалась, а сам статус модели не имеет собственных цветовых стилей в UI.

## 2. Цель

Сделать статус модели визуально понятным и различать три состояния:

- `загружена` — зелёный;
- `загружается` — синий;
- `не загружена` — красный.

## 3. Подход

- Добавить в `useWorkoutSession` явное состояние загрузки модели вместо только бинарного флага готовности.
- Обрабатывать ошибку инициализации модели через `try/catch`, чтобы выставлять отдельный статус ошибки.
- Пробросить новое состояние в `App.tsx`, сохранив текущую блокировку запуска до готовности модели.
- Добавить отдельные стили для `.model-state` и её вариантов `ready`, `loading`, `error`.
- При необходимости синхронизировать краткое описание строки состояния в документации.

## 4. Критерии готовности

- В UI есть три явных состояния текста `Модель:`.
- Цвета статуса соответствуют требованиям: зелёный, синий и красный.
- При ошибке инициализации модель не остаётся в состоянии `загружается`.
- До успешной загрузки модели запуск тренировки остаётся недоступным.
