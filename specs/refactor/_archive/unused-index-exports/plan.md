# Refactor: убрать неиспользуемые exports из index.ts (barrel)

## Контекст

В проекте активно используются barrel-файлы `index.ts`. Со временем в них появляются экспорты, которые больше не импортируются в коде, но продолжают жить в публичном API папок.

## Цель

- Убрать неиспользуемые `export` из `src/**/index.ts`, чтобы API папок оставался актуальным и не разрастался “мертвым” кодом.
- Не менять наблюдаемое поведение приложения.

## Область изменений

- Только правки реэкспортов/экспортов в `index.ts` (и при необходимости — корректировки зависимых barrel-файлов, если где-то были цепочки реэкспортов).
- Без изменения логики компонентов/редьюсеров/сервисов.

## Как проверяем отсутствие регрессий

- `npm run build` (включает `tsc -b` и `vite build`).
- `npm test`.
- `npm run lint`.

## Технический подход

- Скриптом собрать все имена, экспортируемые из `src/**/index.ts`.
- Для каждого имени проверить фактическое использование по проекту через разрешение модулей TypeScript (учитывая `import { ... } from ...` и `export { ... } from ...`).
- Удалить экспорты, которые не используются (кандидаты).
